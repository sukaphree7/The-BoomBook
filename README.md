# The BoomBook

**The BoomBook** is Ryan Duffy's turf spray-rate calculator and application-record system for Pinewood Country Club.

This repository provides the public update feed used by the installed Windows application.

## Updates

BoomBook checks `update.json` to determine whether a newer version is available.

Application records and the SQLite database are stored separately under the user's **Documents/The BoomBook** folder and are not part of program updates.
